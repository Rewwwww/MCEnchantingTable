# 附魔台

适用于《杀戮尖塔2》的Minecraft风格附魔系统。

## 功能特性

- 书本遗物作为书架
- 营火处附魔
- 先古之民处附魔
- 与原版附魔系统的集成
- 自定义附魔界面
- 基于配置的附魔生成

## 版本

0.1.0-alpha

## 开发环境

使用以下工具构建：

- Godot 4.5.1 Mono
- .NET 9
- BaseLib
- ChatGPT
- Codex



# MCEnchantingTable

Minecraft-style enchanting system for Slay the Spire 2.

## Features

- Strange Book relic as bookshelf
- Campfire enchanting
- Ancient enchanting
- Vanilla enchantment integration
- Custom enchantment UI
- Config based enchantment generation

## Version

0.1.0-alpha

- .NET 9
